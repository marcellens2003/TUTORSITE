Undergraduate workflow

Monitors log in, search for any undergraduate tutor, select that tutor's course, and submit the claim on the tutor's behalf.
Tutors remain in ug_tutors as course records only. Monitors are managed in ug_monitors and are the only undergraduate users who need Firebase Authentication accounts.

Bulk add / update tutor course records from Excel

Copy rows from Excel and paste them here. The page will group multiple course rows under the same Staff ID automatically. No tutor Auth accounts will be created.
Recommended column order:
Staff ID | Full Name | Course Code | Course Title | Programme | Study Centre
Course codes are kept exactly as pasted, including the final D. If your file still has a Password column, it will simply be ignored for tutors.
Use replace only when your pasted list is the full correct course list for those tutors.

Add / update one monitor account

Monitors are the undergraduate login users. This creates/verifies the Firebase Authentication account and stores the monitor record in ug_monitors.
Monitor login email will appear here.
For existing monitor accounts, the password is verified. It cannot overwrite an unknown old password.

Bulk add / update monitors from Excel

Paste the monitor attendance-list data here. Repeated Staff IDs are grouped into one monitor account.
Recommended column order:
Staff ID | Full Name | Department/Unit | Password
Password is optional. Blank passwords use 123456. Keep the Staff ID format exactly, for example NSC25/109.
Recommended: 80 or less to stay below Firebase signup limits.
